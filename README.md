# KR Terminal — 국내주식 전 종목 터미널

네모 터미널류의 군더더기(초대·멤버십·광고·토론방)를 모두 덜어내고, **시세 · 수급 · 차트 · 계산기**만 남긴 개인용 국내주식 터미널입니다.
빌드 도구 없이 정적 파일만으로 동작하며 GitHub Pages에서 바로 열립니다.

## 기능

| | |
|---|---|
| 전 종목 | 코스피·코스닥 **2,700여 종목** (ETF 제외 보통주·우선주) 실시간 시세 스냅샷 |
| 외국인 순매수 상위 | 최근 발표된 외국인 순매수 **금액·주수** 정렬, 누적 연속 매수 표시 |
| 연속 매수 필터 | 외국인 **2·3·5·7·10일+ 연속 순매수** |
| 연속 상승 필터 | **2·3·5일+ 연속 상승**, 두 조건 **교집합** 및 종목명·코드 검색 |
| 전일 상승 → 오늘 | 직전 거래일 **상승 마감 종목**만 모아 오늘 등락률·전일 등락률·2일 누적을 나란히 비교, 전일 상승률(+1/3/5/10%↑) 필터와 "전일 상승 중 오늘 상승 비율" 요약 |
| 추세·저PBR | **60·120일선 추세전환**(오늘 또는 최근 5거래일 내 상향 돌파) + **PBR 상한 이하**(기본 1.0배) 종목만 모아 보는 탭. 추세(60/120 돌파·60일선·120일선·60·120 위)와 PBR 상한(1.0/1.2/0.8/0.5) 칩, 행·상세 패널에 PBR 수치 표시 |
| 종목 상세 | **일봉 차트 1년(최대 1년 6개월)** — 캔들·거래량, **이동평균 5·20·60·120일선**, **일목균형표(9·26·52·26, 구름대 양운/음운)**, 3개월/6개월/1년 버튼·휠·핀치 확대축소·드래그 이동, 구간 최고·최저 라벨과 봉별 시·고·저·종가 툴팁 / 이동평균선 위치, 최근 일별 주가·외국인·기관·개인 순매수 |
| 물타기 계산기 | 추가 매수 / 목표 평단 두 가지 모드 |
| 내 종목 | 보유 수량·평단·메모를 **브라우저 localStorage**에만 저장 (서버 전송 없음) |

## 데이터

- 시세·수급: 네이버 금융 (`m.stock.naver.com`, `api.finance.naver.com`)
- PBR: 네이버 금융 종목 통합 API(`/api/stock/{code}/integration`)의 투자지표 — 최근 결산 BPS 대비 현재가
- 지수·환율·해외: 네이버 지수 API + Yahoo Finance (지연 시세)
- 수집 스크립트: `scripts/fetch_market.py` (Python 3.12 표준 라이브러리만 사용)
- 산출물
  - `data/market.json` — 전 종목 요약, 지수/매크로, 연속 일수 계산 결과
  - `data/h/{코드앞2자리}.json` — 종목별 최근 60거래일 OHLCV·수급 (상세 화면에서만 로드)
  - `data/y/{코드앞4자리}.json` — 종목별 최근 380거래일 일봉 OHLCV `[YYMMDD, 시, 고, 저, 종, 거래량]` (차트용, 완결된 봉만 저장하고 당일 봉은 화면에서 이어 붙임)
- 갱신: GitHub Actions `update-market-data`
  - 평일 09:20~15:20 KST 30분 간격, 15:45 KST, 18:10 KST (수급 확정치 반영)
  - 수동 실행: Actions 탭 → `update-market-data` → Run workflow

## 참고

- 외국인·기관 순매수는 네이버 금융이 공개하는 **가장 최근 확정 거래일** 기준입니다.
  장중에는 전일 확정치가, 장 마감 후(18시 이후 수집분)에는 당일 확정치가 표시됩니다. 화면 상단에 기준일이 표시됩니다.
- 야후 파이낸스 값은 지연 시세이며, 수집 실패 시 직전 값을 그대로 유지합니다(`지연` 표기).
- 본 도구는 투자 정보 제공용이며 매매 판단과 책임은 사용자 본인에게 있습니다.

## 개인정보

이 저장소에는 계좌·보유 수량·평단가 등 개인 금융 정보가 **일절 포함되지 않습니다**.
모든 개인 입력값은 사용하는 브라우저의 localStorage에만 남고 어디로도 전송되지 않습니다.
